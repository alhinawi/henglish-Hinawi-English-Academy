Reviewed November 18, 2026.

Challenge mp-3 pairs pen with the personal name Ben. The old gloss also described a box, which does not fit this word. Capitalize the name and explain it as a short form of Benjamin. Keep the p/b sound contrast and existing IPA convention.

- https://dictionary.cambridge.org/dictionary/english/ben : the mountain-name sense is distinct from the personal-name sense used by this exercise.
