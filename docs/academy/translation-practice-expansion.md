# Translation practice expands20to32tasks

Twelve original bilingual tasks added, one in each direction at every CEFRpractice level A1-C2. All have two non-exclusive model translations, specific source context, two vocabulary entries and a grammar note. Existing20tasks exactly preserved. New tasks map to existing licensed study/travel/work/discussion photos with accurate existing captions and stock disclaimer.

Topics include book positions, trip changes, interrupted travel, revised schedules, missed testing, quality under deadlines, policy outcomes, research uncertainty, false binaries and a scrutinized compromise. Intended practice difficulty is not certification. No XP/automatic grading/network changes. TeacherDashboard untouched.
