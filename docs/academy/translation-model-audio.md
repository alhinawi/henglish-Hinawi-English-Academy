# Hear the sample translation

Translation practice already played the source but left target examples silent. Each revealed sample now has an explicit numbered listening button. Target English uses the existing voice pipeline; target Arabic uses supported Microsoft browser voices and is disabled when none is available. The interface explains this limit. No autoplay, new provider or grading. Hiding models and navigation unmount controls and cancel their owned speech. Existing drafts, revisions, hints, grammar notes and checklists stay intact. EN/AR/DE labels.

Verification: regression suite, i18n, TypeScript/full Next static export; EN/AR390 all20 tasks and both target languages, revealed-only controls, source preservation, original/revision draft retention, hide/navigation cleanup and no overflow. Existing grammar/hint/revision tests retained. Actual pixels inspected. Tests use unavailable audio APIs, not proof of actual playback.
