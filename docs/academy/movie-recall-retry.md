# Movie recall second attempt

The weakest part of caption recall was the dead end after revealing the source. Learners can now save their nonempty first draft and attempt the same cue again with the answer hidden. On revealing again, their first draft sits beside the source and a reflection prompt. Current writing stays in the textarea. Each cue has its own first draft, retained during cue navigation and discarded on closing or leaving the clip. One retry per cue, no grades, network calls or saved profile data. Replay may still display player captions and the UI says so.

EN/AR/DE interface, English learner text explicitly LTR. Prior reviewed-cue gate and bounded replay remain. Verification: regression suite, i18n, full static Next build, EN/AR390 UI including empty gate, source hiding, first snapshot retention and close reset. YouTube mocked, no playback claim.
