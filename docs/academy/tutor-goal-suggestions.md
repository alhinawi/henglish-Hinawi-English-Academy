# Assistant-specific practice goals

A blank goal field was an unnecessary barrier for learners unsure what to practise. Each of the seven assistants now offers three original English starter goals, 21 total, inside an optional closed disclosure.

Clicking a suggestion only fills the editable goal field. It never sends a message or writes to the composer. Nonempty goals are protected from replacement until cleared. Existing exact preview, level, language support, correction timing and explicit add-to-message flow remain unchanged. AI availability and response quality are not promised.
