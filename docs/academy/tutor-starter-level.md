# Optional AI-teacher practice level

All seven photo starters now support a learner-selected A1-C2 practice preference. Default is no level request. The selected level is appended to the exact starter preview with a clear statement that it is a preference, not a proficiency assessment. It combines with existing activity style and optional goal.

Changing the selector only changes the preview. Adding to the composer is explicit and stays disabled when a draft already exists. Nothing is sent automatically, no user profile or stored level is changed, and no tutor response quality is promised. Selecting no level removes the request from the preview without changing the composer. Existing modes, photos, style choices, goals, sessions and send workflow remain.

Checks: offline suite, i18n, TypeScript/Next export, EN/AR390px all seven modes x six levels, exact preview, explicit add, no draft overwrite and no autosend; existing seven modes x three styles/goal regression. Backend calls mocked unavailable, so no actual response demonstrated.
