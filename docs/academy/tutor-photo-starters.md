# Tutor scene starters

Each of the seven helper modes reuses one existing licensed photograph. No new image files or remote image dependencies are added. Descriptions state only what is visible, without claims about the models' identity, nationality or relationship to Henglish.

Source and license records remain in `docs/academy-photography-sources.json` and `docs/academy-topic-photography.json`, keyed by the exact image path in `TUTOR_STARTER_PHOTOS`. The seven source images were visually inspected together and the EN/AR 390px cards were inspected in the built page.

Starter text is original learning content, not inferred from image recognition. The helper receives only the text after the learner reviews and sends it through the existing chat. The photo is not uploaded. Adding a starter is disabled when a message draft already exists or a reply is pending, avoiding silent replacement. Modes and existing suggestions remain intact. No automatic proficiency or pronunciation scoring is added.
