# Written word recall in translation practice

Each vocabulary entry in all32translation tasks now includes a private150-character English recall field. Hide the English word, use the Arabic meaning to recall it, then reveal and compare yourself. Hiding and revealing retain the attempt. A per-word clear button returns keyboard focus. Closing help or changing tasks discards attempts.

The word attempt is independent of the full translation draft and model translations. Automatic spelling suggestions, completion and capitalization are disabled for recall practice. No scoring, storage or network calls. EN/AR/DE. TeacherDashboard unchanged.

Verification: offline suite, locale check, full TypeScript/Next export and every word in all32tasks at390px in English and Arabic. Tests cover blank state, independent fields, hide/reveal retention, clear focus, length/overflow and help/task reset. Audio playback is not claimed.
