# Speaking follow-up rewrite focus

Weak piece: 64 lesson-specific follow-up tasks let learners write and retry a private answer but offered no concrete choice of what to improve. This adds one of three focuses before the second draft: answering the task, a relevant reason/detail, or clear order. The chosen focus and prompt remain with the original draft, while the current draft stays editable and independent of the plan/recorder. Choices never rewrite a learner's words.

All 32 lessons and both task modes retain the original prompts, Egyptian meanings, topic words, pictures, checks and recording flow. The keyed component resets the focus on task/lesson/close changes. No scoring, model answer, requests, persistence or audio changes. No TeacherDashboard changes.

Verification: 325 offline checks, Arabic lint, complete Next export/TypeScript build. Production-export tests cover 64 tasks in EN and AR at 390px, all three choices, unchanged draft, saved focus/prompt beside the first draft, empty guards, keyboard focus, clear, collapse, independent plan and reset. Actual screenshots inspected in both languages: readable, English LTR, Arabic RTL, no horizontal overflow, Arabic دخول visible. API blocked in UI tests; no real audio or tutor response claim.
