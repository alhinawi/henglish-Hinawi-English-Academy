# Private written reply for role rehearsal

Role rehearsal previously required jumping from a hidden model straight into recording. An optional closed disclosure now lets learners write their own English reply before speaking, including when a microphone is unavailable.

The 500-character private draft is shown only on the learner's turn. It is separate from model and recorder, preserved through collapse and meaning/model reveal, and discarded on turn/role/restart/close/lesson changes. EN/AR/DE guidance explains that multiple replies can work and this is not automatic correction. Existing dialogue, meaning hints, hidden-model flow, audio and recorder remain unchanged. No persistent storage, requests or scoring. TeacherDashboard untouched.
