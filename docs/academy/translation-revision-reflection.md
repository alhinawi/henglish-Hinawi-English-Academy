# Private revision reflection

Translation practice let learners draft, revise and compare, but did not ask them to explain a change. All 32 tasks now offer a private note for one change to meaning, tense or natural wording, or a question they still have. This supports deliberate revision without claiming an automatic assessment.

The optional 500-character field appears only inside opened revision practice. English/Arabic input is supported with automatic direction, EN/AR/DE guidance and a clear privacy note. Notes are isolated by task, survive filters and hide/reopen in the current practice tab, and disappear when leaving it. Drafts, revisions, model answers, comparison and checklist state remain separate. No requests, storage, scores or rewards added. TeacherDashboard untouched.
