# A chosen focus for caption recall

After comparing a private draft with a reviewed caption, learners can choose key words, small words or spelling/endings for the second listen. Each focus has specific listening guidance, with no claim that a caption contains a given word. The chosen focus stays with that cue and is shown beside the first attempt after starting a second attempt. Closing the activity discards it.

A current-draft clear button returns keyboard focus without removing the saved first attempt or chosen focus. The reviewed-cue gate and original caption text are unchanged. No new source text, scores, persistent storage or network calls. EN/AR/DE labels. TeacherDashboard unchanged.

Verification: offline regression suite, locale check, full TypeScript/Next export and EN/AR390 production UI with a mocked video player. This verifies callbacks and UI, not YouTube playback.
