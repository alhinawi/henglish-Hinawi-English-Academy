# Original photo follow-up challenges

Each of the twelve pronunciation photo tasks now has a distinct optional follow-up question. These ask learners to imagine a relevant situation and add a reason or example, extending the existing one-sentence description into two short sentences.

The questions are original English self-study prompts, not factual descriptions of the stock photograph. Guidance is available in English, Egyptian Arabic and German. The closed-by-default disclosure is independent of the example sentence and private planner, and resets on a photo change. No score, pronunciation assessment, autoplay or network request is added.

Verification covers all twelve prompts, locale parity, full TypeScript/static export, and actual EN/AR 390px UI: hidden default, explicit reveal, English language/direction, draft preservation, model independence, scene/reload reset and loaded photography. Existing navigation, plan and self-review features are preserved.
