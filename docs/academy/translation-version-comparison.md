# Private translation version comparison

All 32 translation practice tasks now let learners compare their original attempt and revised wording in one optional disclosure. It appears only after both versions contain text, within the existing model-gated revision area. On mobile the versions stack; larger displays can show them side by side.

The comparison renders the learner's text as escaped, wrapped paragraphs, preserves line breaks, follows the task's English/Arabic language and direction, and updates as either draft changes. It does not copy, send, grade, replace either draft or alter the self-review checklist. Navigation resets the disclosure through the existing revision gate; returning to a task preserves its private drafts as before.

Verification covers offline guards, locale parity, full TypeScript/static export and EN/AR 390px all 32 tasks: blank gate, closed default, exact escaped multiline content, live edits, independent checklist and drafts, direction/language, long-word wrapping and navigation reset. Existing revision UI remains covered.
