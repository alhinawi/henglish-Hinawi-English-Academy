# Translation language-pattern review

After revealing suggested translations, each of the 20 tasks offers a closed native accordion with its existing Arabic grammar-focus note. English/German labels explicitly identify Arabic. This makes the source explanation available without inventing feedback or grading the learner's draft.

The note remains hidden before answer reveal. Hiding answers or navigating tasks removes the accordion and resets its open state. Drafts, revision and checklist state are unaffected. Existing task-specific context/vocabulary hints remain independent.

Checks: offline regression suite, i18n, TypeScript/Next export, EN/AR390px all20 notes, closed default, answer gating, hide/reopen reset, draft retention, direction and pixels. Existing hints and revision tests remain. External API paths mocked unavailable, no actual translation feedback claim.
