# A second private teacher rehearsal

All seven teacher modes now let learners keep a first private attempt and write a second draft. The first attempt is a one-time snapshot, guarded against blank input. Starting again focuses the empty second draft. Clearing affects only the current draft. Collapsing the activity preserves both; changing teacher mode or leaving clears them.

The existing mode-specific manual review stays independent. Goals, starter previews and the chat composer remain separate. Neither attempt is copied, sent, graded or saved. EN/AR/DE. TeacherDashboard unchanged.
