# Translation task picker

Directly choose among32existing translation tasks, narrowed by CEFR level/direction filters, without stepping through each preceding task. Labels show filtered position, level and direction without revealing source/model text. Navigation hides model/hints/revision panel and retains private per-task drafts/revisions/checklists. Existing previous/next and filters remain. No new scoring, network/storage or XP effects. EN/AR/DE.
