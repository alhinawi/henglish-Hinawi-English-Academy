# Translation practice photography

The twenty original practice tasks share four theme photographs: study, travel, work and discussion. Every image already exists locally and has source/license records in the academy photography ledgers. No new image download or remote dependency is introduced.

Captions describe only visible objects or activities. Each image is explicitly illustrative, not a photograph of the exact event in the source sentence and not Henglish staff or learners. The photo does not change task text, suggested answers, self-review or draft behavior. Four source images and EN/AR mobile layouts were visually inspected.
